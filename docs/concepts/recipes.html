Recipes

A Recipe is a reusable Terraform module registered in an environment. When a resource references a recipe, Ryobi automatically executes the Terraform module to provision infrastructure.

How Recipes Work

  1. Register — Define recipes in your environment YAML under the recipes field
  2. Reference — Application resources reference recipes by name and resource type
  3. Execute — When deployed, Ryobi generates main.tf.json, configures the backend and providers, then runs terraform apply
  4. Output — Terraform outputs are stored on the resource and available to other resources via connections

State Management

Terraform state is stored in PostgreSQL using the native pg backend. Each resource gets an isolated schema derived from its resource ID.
