Deploy an Application

This guide walks through deploying a complete application with Ryobi.

1. Define Your Environment

apiVersion: ryobi/v1
kind: Environment
metadata:
  name: dev
providers:
  azure:
    scope: /subscriptions/xxx/resourceGroups/my-rg
recipes:
  Applications.Datastores/postgresDatabases:
    default:
      templateKind: terraform
      templatePath: ghcr.io/myorg/recipes/postgres:1.0

2. Define Your Application

apiVersion: ryobi/v1
kind: Application
metadata:
  name: my-app
  environment: dev
resources:
  - name: database
    type: Applications.Datastores/postgresDatabases
    recipe: default

3. Deploy

ryobi deploy env.yaml
ryobi deploy app.yaml

4. Monitor

ryobi app status my-app
