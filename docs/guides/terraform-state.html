Terraform State

Ryobi manages Terraform state automatically. You do not need to configure backends manually.

PostgreSQL Backend

In production, Terraform state is stored in PostgreSQL using the native pg backend. Each resource gets a unique schema name derived from its resource ID (SHA-256 hash).

terraform {
  backend "pg" {
    conn_str    = "postgres://ryobi:pass@localhost/ryobi"
    schema_name = "tfstate_a1b2c3d4"
  }
}

Local Backend

For development (when RYOBI_DB_URL is not set), state is stored as local files under the Terraform root directory.

State Isolation

Each resource gets its own isolated state. Deploying or destroying one resource never affects another.
