Create a Recipe

Recipes are standard Terraform modules. Any module that accepts variables and produces outputs can be used as a recipe.

Module Structure

# main.tf
resource "azurerm_postgresql_flexible_server" "this" {
  name                = var.name
  resource_group_name = var.resource_group
  location            = var.location
  sku_name            = var.sku
  ...
}

output "connectionString" {
  value     = azurerm_postgresql_flexible_server.this.connection_string
  sensitive = true
}

Register in Environment

recipes:
  Applications.Datastores/postgresDatabases:
    default:
      templateKind: terraform
      templatePath: ghcr.io/myorg/recipes/postgres:1.0

The templatePath can be any valid Terraform module source: OCI registry, Git URL, HTTP URL, or local path.
