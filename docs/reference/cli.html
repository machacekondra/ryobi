CLI Commands

Complete reference for all ryobi CLI commands.

Global Flags

FlagDescription
--server <url>Server URL (default: from ~/.ryobi/config.yaml or http://localhost:9000)
--helpShow help for any command

ryobi deploy

Deploy an application from a YAML definition file.

ryobi deploy <file> [flags]
FlagDescription
-e, --environment <name>Override target environment
--waitWait for async operations to complete (default: true)

Supports multi-document YAML files. Environments are processed before applications.

ryobi env

Manage environments.

CommandDescription
ryobi env listList all environments
ryobi env show <name>Show environment details as JSON
ryobi env delete <name>Delete an environment

ryobi app

Manage applications.

CommandDescription
ryobi app listList all applications
ryobi app show <name>Show application details as JSON
ryobi app status <name>Show application resources and their states
ryobi app delete <name>Delete an application

ryobi resource

Manage Terraform-managed resources within an application.

CommandDescription
ryobi resource list --app <name>List resources in an application
ryobi resource show <name> --app <app>Show resource details and outputs
ryobi resource delete <name> --app <app>Delete a resource (runs terraform destroy)

ryobi recipe

View recipes registered in environments.

CommandDescription
ryobi recipe list -e <env>List recipes registered in an environment

ryobi placement

Manage administrator-defined placement rules. Placement rules determine which environment handles a resource type when no explicit environment is specified.

CommandDescription
ryobi placement listList all placement rules
ryobi placement show <name>Show rule details
ryobi placement create <name> [flags]Create a placement rule
ryobi placement delete <name>Delete a placement rule

Create flags:

FlagDescription
--resource-type <type>Resource type this rule applies to (required)
--region <region>Required region constraint
--sovereignty <zone>Required sovereignty constraint
--cost minimizePrefer cheapest environment
--available-resources maximizePrefer most free capacity
--priority <int>Rule priority (higher wins, default 0)

ryobi version

Show CLI version information.

ryobi version
# ryobi version 0.1.0-dev (commit: abc1234, channel: dev)

Examples

# Set up placement rules (admin)
ryobi placement create eu-containers \
  --resource-type Ryobi.Compute/containers \
  --region eu-west-1 --sovereignty eu --priority 10
ryobi placement create cost-fallback \
  --resource-type Ryobi.Compute/containers \
  --cost minimize --priority 1
ryobi placement list

# Deploy an application (placement selects environment automatically)
ryobi deploy examples/placement-app.yaml

# Deploy with explicit environment
ryobi deploy app.yaml -e staging

# Check what was deployed
ryobi app status my-app

# View resource details
ryobi resource show api --app my-app

# Clean up (deletes all resources first, then the app)
ryobi app delete my-app
