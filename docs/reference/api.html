API Reference

Ryobi exposes a flat REST API on the ryobid server (default port 9000).

Endpoints

MethodPathDescription
GET/api/v1/environmentsList environments
PUT/api/v1/environments/{name}Create/update environment
GET/api/v1/environments/{name}Get environment
DELETE/api/v1/environments/{name}Delete environment
GET/api/v1/applicationsList applications
PUT/api/v1/applications/{name}Create/update application
GET/api/v1/applications/{name}Get application
DELETE/api/v1/applications/{name}Delete application
GET/api/v1/applications/{app}/resourcesList resources
PUT/api/v1/applications/{app}/resources/{name}Create/update resource (async 202)
GET/api/v1/applications/{app}/resources/{name}Get resource
DELETE/api/v1/applications/{app}/resources/{name}Delete resource (async 202)
GET/api/v1/operations/{id}Get operation status

Response Format

All responses are JSON. List responses wrap results in a value array:

{"value": [...]}

Async operations return 202 Accepted with a Location header pointing to the operation status URL.
