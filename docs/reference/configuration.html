Configuration

Server Configuration

The ryobid server is configured via environment variables:

VariableDefaultDescription
RYOBI_ADDRESS0.0.0.0:9000Server listen address
RYOBI_DB_URL(none)PostgreSQL connection URL. Enables PG state backend.
RYOBI_TF_ROOT_DIR/var/lib/ryobi/terraformTerraform working directory
TERRAFORM_PATHterraformPath to terraform binary

CLI Configuration

The CLI reads from ~/.ryobi/config.yaml:

currentEnvironment: dev
server:
  url: http://localhost:9000

Override with the --server flag:

ryobi --server http://ryobi.example.com:9000 env list
