Configuration

Server Configuration (ryobid)

Configured via environment variables:

VariableDefaultDescription
RYOBI_ADDRESS0.0.0.0:9000HTTP API listen address
RYOBI_GRPC_ADDRESS0.0.0.0:9001gRPC listen address (for environment agents)

Environment Agent Configuration (ryobi-env)

Configured via a YAML config file passed as an argument:

ryobi-env config.yaml
FieldDefaultDescription
name(required)Environment name
server.grpcAddresslocalhost:9001ryobid gRPC endpoint
providers{}Cloud provider scopes
terraformProviders{}Terraform provider blocks (e.g. kubeconfig path)
recipes[]Recipe definitions (resource type, name, template path)
terraform.binaryPathterraformPath to terraform binary
terraform.workDir~/.ryobi/terraformTerraform working directory
terraform.databaseUrl(none)PostgreSQL URL for TF state backend

Template paths in recipes are resolved relative to the config file's directory.

CLI Configuration

The CLI reads from ~/.ryobi/config.yaml:

server:
  url: http://localhost:9000

Override with the --server flag:

ryobi --server http://ryobi.example.com:9000 env list
