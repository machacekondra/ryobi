Why Ryobi?

⚙️

Terraform Recipes

Define reusable infrastructure templates as Terraform modules. Register once, deploy everywhere.

📄

YAML Definitions

Declare your entire application stack in simple, human-readable YAML. No proprietary languages needed.

☁️

Multi-Cloud & Kubernetes

Deploy to Azure, AWS, Kubernetes, or KubeVirt. Ships with built-in recipes for containers and VMs.

📦

Lightweight

Runs as a single binary with PostgreSQL. Deploy the platform via Podman or systemd.

🎯

Smart Placement

Automatically select the best environment per resource based on region, cost, capacity, and sovereignty constraints.

Install Ryobi

Start with a single command:

podman-compose -f deploy/podman-compose.yaml up -d
