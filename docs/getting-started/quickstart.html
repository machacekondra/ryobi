Quick Start

Get up and running with Ryobi in under 5 minutes.

Prerequisites

  • Podman and podman-compose installed
  • Terraform CLI installed
  • Go 1.24+ (if building from source)

Step 1: Start the Platform

Clone the repository and start Ryobi using Podman Compose:

git clone https://github.com/ryobi-project/ryobi.git
cd ryobi
podman-compose -f deploy/podman-compose.yaml up -d

This starts PostgreSQL and the ryobid server on port 9000.

Step 2: Build All Binaries

make build
# Produces: dist/ryobi, dist/ryobid, dist/ryobi-env

Verify:

./dist/ryobi version

Step 3: Start the Server

In a separate terminal:

./dist/ryobid
# HTTP API on :9000, gRPC on :9001

Step 4: Start an Environment Agent

In another terminal, start the environment agent with the example Kubernetes config:

./dist/ryobi-env examples/env-kubernetes.yaml

This registers the dev environment with the server, including the built-in container and VM recipes. The agent watches for resource events and executes Terraform locally.

Step 5: Define Your Application

Create an application YAML that references your environment and recipes:

# app.yaml
apiVersion: ryobi/v1
kind: Application
metadata:
  name: my-app
  environment: dev
resources:
  - name: nginx
    type: Ryobi.Compute/containers
    recipe: kubernetes
    parameters:
      name: nginx
      image: nginx:1.25-alpine
      replicas: 2
      ports:
        - container_port: 80

Step 6: Deploy

Deploy the application:

./dist/ryobi deploy app.yaml

Or use the included example:

./dist/ryobi deploy examples/container-nginx.yaml

Step 7: Check Status

# List environments
ryobi env list

# Check application status
ryobi app status my-app

# View resource details
ryobi resource show nginx --app my-app
What's next?

Learn about Environments to understand the agent model, Recipes to see how Terraform modules power deployments, or follow the Deploy an Application guide for a complete walkthrough.
