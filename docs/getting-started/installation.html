Installation

From Source

git clone https://github.com/ryobi-project/ryobi.git
cd ryobi
make build
cp dist/ryobi /usr/local/bin/

Platform Deployment

Deploy the ryobid server using Podman Compose:

podman-compose -f deploy/podman-compose.yaml up -d

Or run as a systemd service:

sudo cp dist/ryobid /usr/local/bin/
sudo cp deploy/systemd/ryobid.service /etc/systemd/system/
sudo systemctl enable --now ryobid
